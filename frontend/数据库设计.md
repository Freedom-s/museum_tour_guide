# 博物馆智能导览系统 - 数据库设计文档

## 概述

本文档描述了博物馆智能导览系统的数据库表结构设计。

**数据库选型**：PostgreSQL 14+
**字符集**：UTF-8
**命名规范**：蛇形命名法 (snake_case)

---

## 数据库概览

| 表名 | 说明 | 主要功能 |
|------|------|----------|
| `users` | 用户表 | 用户账户管理 |
| `artifacts` | 文物表 | 文物基本信息 |
| `artifact_images` | 文物图片表 | 文物图片存储 |
| `conversations` | 对话表 | 用户对话会话 |
| `messages` | 消息表 | 对话消息记录 |
| `user_feedback` | 用户反馈表 | 识别结果反馈 |
| `embeddings` | 向量嵌入表 | 向量数据存储（可选） |

## 表结构详细设计

### 1. 用户表 (users)

存储系统用户信息，支持未来的用户认证功能。

| 字段名 | 类型 | 长度 | 允许NULL | 默认值 | 约束 | 说明 |
|--------|------|------|----------|--------|------|------|
| `id` | UUID | - | NO | - | PK | 用户唯一标识 |
| `username` | VARCHAR | 50 | NO | - | UNIQUE | 用户名 |
| `email` | VARCHAR | 100 | NO | - | UNIQUE | 邮箱 |
| `password_hash` | VARCHAR | 255 | NO | - | - | 密码哈希（bcrypt） |
| `avatar_url` | VARCHAR | 500 | YES | NULL | - | 头像URL |
| `role` | VARCHAR | 20 | NO | 'user' | - | 角色：admin/user |
| `is_active` | BOOLEAN | - | NO | true | - | 账户是否激活 |
| `last_login_at` | TIMESTAMP | - | YES | NULL | - | 最后登录时间 |
| `created_at` | TIMESTAMP | - | NO | CURRENT_TIMESTAMP | - | 创建时间 |
| `updated_at` | TIMESTAMP | - | NO | CURRENT_TIMESTAMP | - | 更新时间 |

**索引设计**：

```sql
CREATE UNIQUE INDEX idx_users_username ON users(username);
CREATE UNIQUE INDEX idx_users_email ON users(email);
CREATE INDEX idx_users_created_at ON users(created_at);
```

**DDL 语句**：

```sql
CREATE TABLE users (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    username VARCHAR(50) NOT NULL UNIQUE,
    email VARCHAR(100) NOT NULL UNIQUE,
    password_hash VARCHAR(255) NOT NULL,
    avatar_url VARCHAR(500),
    role VARCHAR(20) NOT NULL DEFAULT 'user' CHECK (role IN ('admin', 'user')),
    is_active BOOLEAN NOT NULL DEFAULT true,
    last_login_at TIMESTAMP,
    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP
);

-- 更新时间触发器
CREATE TRIGGER update_users_updated_at
    BEFORE UPDATE ON users
    FOR EACH ROW
    EXECUTE FUNCTION update_updated_at_column();
```

### 2. 文物表 (artifacts)

存储文物的基本信息。

| 字段名 | 类型 | 长度 | 允许NULL | 默认值 | 约束 | 说明 |
|--------|------|------|----------|--------|------|------|
| `id` | UUID | - | NO | - | PK | 文物唯一标识 |
| `name` | VARCHAR | 200 | NO | - | - | 文物名称 |
| `description` | TEXT | - | YES | NULL | - | 文物描述 |
| `category` | VARCHAR | 100 | YES | NULL | - | 分类：青铜器/陶瓷/玉器/书画等 |
| `era` | VARCHAR | 100 | YES | NULL | - | 年代：商/周/秦/汉/唐/宋/元/明/清等 |
| `dimensions` | VARCHAR | 200 | YES | NULL | - | 尺寸：高24cm, 口径18cm |
| `material` | VARCHAR | 100 | YES | NULL | - | 材质：青铜/陶/玉/瓷等 |
| `collection_number` | VARCHAR | 100 | YES | NULL | UNIQUE | 收藏编号 |
| `location` | VARCHAR | 200 | YES | NULL | - | 存放位置 |
| `status` | VARCHAR | 20 | NO | 'active' | - | 状态：active/archived |
| `created_by` | UUID | - | YES | NULL | FK users(id) | 创建人 |
| `created_at` | TIMESTAMP | - | NO | CURRENT_TIMESTAMP | - | 创建时间 |
| `updated_at` | TIMESTAMP | - | NO | CURRENT_TIMESTAMP | - | 更新时间 |

**索引设计**：

```sql
CREATE INDEX idx_artifacts_name ON artifacts(name);
CREATE INDEX idx_artifacts_category ON artifacts(category);
CREATE INDEX idx_artifacts_era ON artifacts(era);
CREATE INDEX idx_artifacts_status ON artifacts(status);
CREATE INDEX idx_artifacts_created_at ON artifacts(created_at DESC);
-- 全文搜索索引
CREATE INDEX idx_artifacts_description_fts ON artifacts USING gin(to_tsvector('chinese', description));
```

**DDL 语句**：

```sql
CREATE TABLE artifacts (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    name VARCHAR(200) NOT NULL,
    description TEXT,
    category VARCHAR(100),
    era VARCHAR(100),
    dimensions VARCHAR(200),
    material VARCHAR(100),
    collection_number VARCHAR(100) UNIQUE,
    location VARCHAR(200),
    status VARCHAR(20) NOT NULL DEFAULT 'active' CHECK (status IN ('active', 'archived')),
    created_by UUID REFERENCES users(id) ON DELETE SET NULL,
    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP
);

CREATE TRIGGER update_artifacts_updated_at
    BEFORE UPDATE ON artifacts
    FOR EACH ROW
    EXECUTE FUNCTION update_updated_at_column();
```

### 7. 向量嵌入表 (embeddings)

存储文物描述和图片的向量嵌入数据（可选，也可使用专门的向量数据库）。

| 字段名 | 类型 | 长度 | 允许NULL | 默认值 | 约束 | 说明 |

| `artifact_id` | UUID | - | NO | - | FK artifacts(id) | 关联文物ID |
| `artifact_image_id` | UUID | - | YES | NULL | FK artifact_images(id) | 关联文物图片ID |
| `vector` | VECTOR | - | NO | - | - | 向量数据（需pgvector扩展） |
| `model` | VARCHAR | 100 | NO | - | - | 使用的模型名称 |
| `embedding_type` | VARCHAR | 20 | NO | - | - | 类型：text/image/multimodal |
| `created_at` | TIMESTAMP | - | NO | CURRENT_TIMESTAMP | - | 创建时间 |

> **注意**：此表需要安装 PostgreSQL 的 `pgvector` 扩展。

**索引设计**：

```sql
-- 向量相似度搜索索引
CREATE INDEX idx_embeddings_vector ON embeddings USING ivfflat (vector vector_cosine_ops);
```

**DDL 语句**：

```sql
-- 启用 pgvector 扩展
CREATE EXTENSION IF NOT EXISTS vector;

CREATE TABLE embeddings (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    artifact_id UUID NOT NULL REFERENCES artifacts(id) ON DELETE CASCADE,
    artifact_image_id UUID REFERENCES artifact_images(id) ON DELETE SET NULL,
    vector VECTOR(1024) NOT NULL,  -- 向量维度根据模型调整
    model VARCHAR(100) NOT NULL,
    embedding_type VARCHAR(20) NOT NULL CHECK (embedding_type IN ('text', 'image', 'multimodal')),
    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_embeddings_artifact_id ON embeddings(artifact_id);
CREATE INDEX idx_embeddings_vector ON embeddings USING ivfflat (vector vector_cosine_ops) WITH (lists = 100);
```

## 通用函数和触发器

### 更新时间触发器函数

```sql
CREATE OR REPLACE FUNCTION update_updated_at_column()
RETURNS TRIGGER AS $$
BEGIN
    NEW.updated_at = CURRENT_TIMESTAMP;
    RETURN NEW;
END;
$$ language 'plpgsql';
```

### 生成收藏编号函数

```sql
CREATE OR REPLACE FUNCTION generate_collection_number()
RETURNS TRIGGER AS $$
DECLARE
    era_abbrev VARCHAR(10);
    category_abbrev VARCHAR(10);
    seq_num INTEGER;
    collection_no VARCHAR(50);
BEGIN
    -- 根据年代和类别生成缩写
    era_abbrev := SUBSTRING(NEW.era FROM 1 FOR 1);
    category_abbrev := SUBSTRING(NEW.category FROM 1 FOR 2);

    -- 获取当日序号
    SELECT COALESCE(MAX(CAST(SUBSTRING(collection_number FROM '[0-9]+$') AS INTEGER)), 0) + 1
    INTO seq_num
    FROM artifacts
    WHERE DATE(created_at) = CURRENT_DATE;

    -- 生成收藏编号：如 "SQT-20240215-001"
    collection_no := era_abbrev || category_abbrev || '-' || TO_CHAR(CURRENT_DATE, 'YYYYMMDD') || '-' || LPAD(seq_num::TEXT, 3, '0');

    NEW.collection_number := collection_no;
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

-- 在插入文物前自动生成收藏编号
CREATE TRIGGER generate_artifact_collection_number
    BEFORE INSERT ON artifacts
    FOR EACH ROW
    WHEN (NEW.collection_number IS NULL)
    EXECUTE FUNCTION generate_collection_number();
```

## 视图设计

### 1. 文物详情视图 (v_artifact_details)

```sql
CREATE VIEW v_artifact_details AS
SELECT
    a.id,
    a.name,
    a.description,
    a.category,
    a.era,
    a.dimensions,
    a.material,
    a.collection_number,
    a.location,
    a.status,
    a.created_at,
    a.updated_at,
    json_agg(
        json_build_object(
            'id', ai.id,
            'url', ai.image_url,
            'order', ai."order",
            'is_primary', ai.is_primary
        ) ORDER BY ai."order"
    ) as images,
    u.username as created_by_username
FROM artifacts a
LEFT JOIN artifact_images ai ON a.id = ai.artifact_id
LEFT JOIN users u ON a.created_by = u.id
GROUP BY a.id, u.username;
```

### 2. 对话摘要视图 (v_conversation_summary)

```sql
CREATE VIEW v_conversation_summary AS
SELECT
    c.id,
    c.user_id,
    c.title,
    c.artifact_id,
    c.message_count,
    c.created_at,
    c.updated_at,
    a.name as artifact_name,
    (SELECT content FROM messages WHERE conversation_id = c.id AND role = 'user' ORDER BY created_at LIMIT 1) as first_message,
    (SELECT content FROM messages WHERE conversation_id = c.id ORDER BY created_at DESC LIMIT 1) as last_message
FROM conversations c
LEFT JOIN artifacts a ON c.artifact_id = a.id;
```

## 数据库备份策略

### 备份方案

1. **全量备份**：每周日凌晨执行
2. **增量备份**：每天凌晨执行
3. **归档日志**：实时归档

### 备份命令示例

```bash
# 全量备份
pg_dump -h localhost -U postgres -d museum_guide > backup_$(date +%Y%m%d).sql

# 压缩备份
pg_dump -h localhost -U postgres -d museum_guide | gzip > backup_$(date +%Y%m%d).sql.gz

# 恢复
psql -h localhost -U postgres -d museum_guide < backup_20240215.sql
```

```sql
CREATE TABLE messages (
    -- ... 字段定义
) PARTITION BY RANGE (created_at);

-- 创建月度分区
CREATE TABLE messages_2024_01 PARTITION OF messages
    FOR VALUES FROM ('2024-01-01') TO ('2024-02-01');
```

```ini
# postgresql.conf
max_connections = 100
```

## 安全建议

1. **最小权限原则**：应用使用专用数据库用户，只授予必要权限
2. **敏感数据加密**：密码使用 bcrypt 哈希存储
3. **SQL注入防护**：使用参数化查询
4. **审计日志**：记录关键操作日志
5. **定期备份**：建立完善的备份恢复机制
